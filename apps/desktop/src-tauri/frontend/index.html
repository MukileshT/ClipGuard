Windows keeps a clipboard history

Windows stores everything you copy in its own clipboard history (the panel that opens with Win+V). The original secret is recorded there before ClipGuard masks the clipboard, so it can be pasted again later — and with the cloud clipboard it even travels to your other devices.

Turning the history off stops Windows from keeping your secrets. Entries that are already there have to be deleted once with Win+V → Clear.

About ClipGuard

ClipGuard is a native Windows clipboard security firewall. It watches the clipboard, detects credentials and personal data locally and protects them before they reach another application.

  • All detection happens on this machine — there is no network traffic.
  • Secrets never appear in logs, statistics or the configuration file.
  • No clipboard history is stored.
  • No administrator privileges are required.

Windows does not offer a race free API to intercept every paste. ClipGuard combines clipboard monitoring, controlled clipboard replacement and a low level keyboard hook. It reduces accidental exposure, it does not guarantee that no data ever leaves the machine.
